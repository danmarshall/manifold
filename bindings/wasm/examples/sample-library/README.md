# my-manifold-shapes

A sample library that demonstrates how to use `manifold-3d` from npm to create reusable 3D shapes.

## Installation

```bash
npm install my-manifold-shapes
```

## Usage

```typescript
import { createCubeWithHole } from 'my-manifold-shapes';

// Create a cube with a cylinder subtracted from it
const shape = await createCubeWithHole(
  [100, 100, 100],  // cube size
  30,               // cylinder radius
  120               // cylinder height
);

// The shape is a Manifold object that can be further manipulated
```

## Development

This library uses `manifold-3d` as a dependency.

### Setup

```bash
npm install
npm run build
```

### Project Structure

```
my-manifold-shapes/
├── package.json
├── tsconfig.json
├── src/
│   └── index.ts
└── dist/           (generated by build)
    ├── index.js
    └── index.d.ts
```

## How This Works

This library:
1. Imports `manifold-3d` as an npm dependency
2. Initializes the WASM module
3. Provides reusable functions that create Manifold shapes
4. Exports TypeScript types for type safety

## Publishing

To publish this library to npm:

```bash
npm publish
```

Note: You need to be logged in to npm and have a unique package name.
