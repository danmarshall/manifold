# my-manifold-shapes

A sample library that demonstrates how to create reusable 3D shape functions with `manifold-3d`.

## Key Architecture Principle

**This library does NOT initialize the WASM module.** Instead, it expects the caller to initialize manifold-3d once and pass in the Manifold class. This is a lightweight, efficient pattern that avoids multiple WASM initializations.

## Installation

```bash
npm install my-manifold-shapes
```

Note: `manifold-3d` is a peer dependency - you need to install it in your application.

## Usage

```typescript
import Module from 'manifold-3d';
import { createCubeWithHole } from 'my-manifold-shapes';

// Initialize WASM module ONCE in your application
const wasm = await Module();
wasm.setup();
const { Manifold } = wasm;

// Pass the Manifold class to the library function
const shape = createCubeWithHole(Manifold, {
  cubeSize: [100, 100, 100],
  cylinderRadius: 30,
  cylinderHeight: 120,
  radiusScale: 1.0
});

// The shape is a Manifold object that can be further manipulated
```

## Why This Pattern?

### ❌ Bad: Multiple WASM Initializations
```typescript
// DON'T DO THIS - each part initializes its own WASM module
async function createGear() {
  const wasm = await Module();  // Heavy!
  wasm.setup();
  // ... create gear
}

async function createBearing() {
  const wasm = await Module();  // Heavy again!
  wasm.setup();
  // ... create bearing
}
```

### ✅ Good: Shared WASM Module
```typescript
// DO THIS - initialize once, pass everywhere
const wasm = await Module();  // Only once!
wasm.setup();
const { Manifold } = wasm;

const gear = createGear(Manifold, params);
const bearing = createBearing(Manifold, params);
const shaft = createShaft(Manifold, params);
```

This is especially important for complex models with many parts - like a bicycle with hundreds of components. You want one WASM instance, not hundreds!

## How This Works

This library:
1. Has `manifold-3d` as a **peer dependency** (not regular dependency)
2. Does NOT initialize WASM - caller's responsibility
3. Accepts Manifold class as the first parameter to all functions
4. Creates and returns Manifold objects using the passed-in class
5. Exports TypeScript interfaces for type safety
