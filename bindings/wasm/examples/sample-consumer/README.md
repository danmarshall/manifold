# my-3d-app

A sample application that demonstrates how to consume a library built with `manifold-3d`.

## Setup

1. First, build the library:
   ```bash
   cd ../sample-library
   npm install
   npm run build
   cd ../sample-consumer
   ```

2. Install dependencies (this will link to the local library):
   ```bash
   npm install
   ```

3. Build the application:
   ```bash
   npm run build
   ```

4. Run the application:
   ```bash
   npm start
   ```

## What This Demonstrates

This project shows how to:
- Consume a library that uses `manifold-3d`
- Import and use functions from that library
- Work with Manifold objects returned by the library
- The library dependency (`my-manifold-shapes`) handles all the `manifold-3d` initialization

## Project Structure

```
my-3d-app/
├── package.json          (depends on my-manifold-shapes)
├── tsconfig.json
├── src/
│   └── app.ts           (uses createCubeWithHole from library)
└── dist/                (generated by build)
    └── app.js
```

## How Dependencies Work

```
my-3d-app (this project)
  └── depends on my-manifold-shapes (the library)
      └── depends on manifold-3d (npm package)
```

When you install this project:
- npm installs `my-manifold-shapes` (from local file path or npm)
- `my-manifold-shapes` brings in `manifold-3d` as its dependency
- Your app code only needs to import from `my-manifold-shapes`

## Publishing Scenario

If `my-manifold-shapes` were published to npm:

1. Change `package.json` to use the published version:
   ```json
   "dependencies": {
     "my-manifold-shapes": "^1.0.0"
   }
   ```

2. Run `npm install` to get it from npm registry

3. Everything else stays the same!
