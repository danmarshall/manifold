# Sample Projects: Library, Consumer, and Viewer

This directory contains three sample projects that demonstrate how to use `manifold-3d` from npm in a library, consume that library in another project, and visualize the results with Three.js.

## Project Overview

### 1. sample-library (`my-manifold-shapes`)
A library that uses `manifold-3d` to create reusable 3D shapes.

**Key Features:**
- Uses `manifold-3d` as a dependency
- Exports `createCubeWithHole()` that subtracts a cylinder from a cube
- Supports a `radiusScale` parameter for controlling cylinder size
- Can be published to npm
- Provides TypeScript types

### 2. sample-consumer (`my-3d-app`)
An application that uses the `my-manifold-shapes` library and adds its own shapes.

**Key Features:**
- Depends on `my-manifold-shapes` (locally via file path)
- Creates its own shapes (ring of spheres)
- Combines library shapes with custom shapes into a scene
- Exports `createScene()` function with parameters
- Demonstrates the dependency chain: app → library → manifold-3d

### 3. sample-viewer (`my-3d-viewer`)
A Three.js-based web viewer that renders the scene from `my-3d-app`.

**Key Features:**
- Depends on `my-3d-app`
- Real-time Three.js rendering with lighting
- Interactive UI with sliders for parameters:
  - Library cylinder radius scale (0.1 to 2.0)
  - Sphere count (1 to 12)
- Auto-rotating scene
- Uses Vite for development

## Quick Start

### Full Stack Setup

```bash
# Step 1: Build the library
cd sample-library
npm install && npm run build

# Step 2: Build the consumer
cd ../sample-consumer
npm install && npm run build

# Step 3: Run the viewer
cd ../sample-viewer
npm install
npm run dev
```

Then open http://localhost:3000 in your browser to see the interactive 3D viewer!

## Alternative: Build Each Project Separately

### Step 1: Build the Library

```bash
cd sample-library
npm install
npm run build
cd ..
```

This creates:
- `node_modules/` with manifold-3d installed
- `dist/index.js` and `dist/index.d.ts` compiled from TypeScript

### Step 2: Build and Run the Consumer

```bash
cd sample-consumer
npm install

npm start
```

Expected output:


### Step 3: Run the Viewer (Optional)

```bash
cd sample-viewer
npm install
npm run dev
```

Then open http://localhost:3000 to see the interactive Three.js viewer with parameter sliders.

## How It Works

### Library Project Structure

```
sample-library/
├── package.json           # depends on manifold-3d
├── tsconfig.json
├── src/
│   └── index.ts          # exports createCubeWithHole()
├── dist/                 # generated by tsc
│   ├── index.js
│   └── index.d.ts
└── README.md
```

**Key Code (src/index.ts):**
```typescript
import Module from 'manifold-3d';

export async function createCubeWithHole(
  cubeSize: [number, number, number] = [100, 100, 100],
  cylinderRadius: number = 30,
  cylinderHeight: number = 120
) {
  const wasm = await Module();
  wasm.setup();
  const { Manifold } = wasm;

  const cube = Manifold.cube(cubeSize, true);
  const cylinder = Manifold.cylinder(cylinderHeight, cylinderRadius, cylinderRadius);
  const result = cube.subtract(cylinder);

  return result;
}
```

### Consumer Project Structure

```
sample-consumer/
├── package.json           # depends on my-manifold-shapes
├── tsconfig.json
├── src/
│   └── app.ts            # imports from my-manifold-shapes
├── dist/                 # generated by tsc
│   └── app.js
└── README.md
```

**Key Code (src/app.ts):**
```typescript
import { createCubeWithHole } from 'my-manifold-shapes';

async function main() {
  const shape = await createCubeWithHole([100, 100, 100], 30, 120);
  console.log('Shape created!');
  console.log('Vertices:', shape.numVert());
  shape.delete();
}
```

## Dependency Chain

### Complete Stack (All Three Projects)

```
my-3d-viewer (sample-viewer)
  ↓ imports createScene from
my-3d-app (sample-consumer)
  ↓ imports createCubeWithHole from
my-manifold-shapes (sample-library)
  ↓ depends on
manifold-3d (npm package)
  ↓ contains
manifold.wasm (WebAssembly binary)
```

### Parameter Flow

```
User adjusts sliders in viewer
  ↓
viewer.ts calls createScene({ libraryRadiusScale, sphereCount })
  ↓
sample-consumer creates spheres (sphereCount) and calls library
  ↓
sample-library creates cube with scaled cylinder (radiusScale)
  ↓
Results flow back up: Manifold → Three.js Geometry → Rendered scene
```

### Technology Stack

- **sample-library**: TypeScript, manifold-3d (WASM)
- **sample-consumer**: TypeScript, manifold-3d (via library)
- **sample-viewer**: TypeScript, Three.js, Vite

## Publishing to npm

### If you were to publish the library:

1. **Update library package.json:**
   ```json
   {
     "name": "@yourscope/manifold-shapes",
     "version": "1.0.0",
     "dependencies": {
       "manifold-3d": "^3.3.2"
     }
   }
   ```

2. **Publish the library:**
   ```bash
   cd sample-library
   npm publish --access public
   ```

3. **Update consumer package.json:**
   ```json
   {
     "dependencies": {
       "@yourscope/manifold-shapes": "^1.0.0"
     }
   }
   ```

4. **Install in consumer:**
   ```bash
   cd sample-consumer
   npm install
   ```

The consumer would now get the library from npm instead of a local file path!

## Key Takeaways

### ✅ Libraries can use manifold-3d as a dependency
Your library's `package.json` lists `manifold-3d` as a dependency, and npm handles installation.

### ✅ Consumers don't need to know about manifold-3d
The consumer just imports from your library. The manifold-3d dependency is transitive.

### ✅ Works with standard npm workflows
- `npm install` to get dependencies
- `npm run build` to compile TypeScript
- `npm publish` to publish the library
- Standard semantic versioning

### ✅ Type safety with TypeScript
Both the library and consumer get full TypeScript support and type checking.

### ✅ WASM initialization is handled once
The library initializes the WASM module, and returns ready-to-use Manifold objects.

## Troubleshooting

### "Cannot find module 'manifold-3d'"
Make sure you've run `npm install` in the library directory first.

### "Cannot find module 'my-manifold-shapes'"
Make sure you've:
1. Built the library (`npm run build` in sample-library)
2. Run `npm install` in sample-consumer

### TypeScript errors
Make sure you've run `npm install` to get the type definitions.

## Alternative: Using in Node.js without TypeScript

If you don't want to use TypeScript:

1. **Library (index.js):**
   ```javascript
   import Module from 'manifold-3d';
   
   export async function createCubeWithHole(cubeSize, cylinderRadius, cylinderHeight) {
     const wasm = await Module();
     wasm.setup();
     const { Manifold } = wasm;
     
     const cube = Manifold.cube(cubeSize, true);
     const cylinder = Manifold.cylinder(cylinderHeight, cylinderRadius, cylinderRadius);
     return cube.subtract(cylinder);
   }
   ```

2. **Consumer (app.js):**
   ```javascript
   import { createCubeWithHole } from 'my-manifold-shapes';
   
   const shape = await createCubeWithHole([100, 100, 100], 30, 120);
   console.log('Vertices:', shape.numVert());
   ```

3. **Both package.json files need:**
   ```json
   {
     "type": "module"
   }
   ```
